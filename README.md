# georgeathanaso.github.io

Personal portfolio for George Athanasopoulos, prepared as a static, privacy-conscious GitHub Pages site.

## Principles

- Original visual identity inspired by high-end editorial portfolios, without copying source code or branded assets.
- Native WebGL background with no external runtime dependency.
- Sound is off by default and starts only after explicit visitor interaction.
- Mobile and reduced-motion fallbacks are built in.
- Only public-safe project descriptions and selected screenshots are included.
- Private source code, credentials, infrastructure details and customer data are not part of this repository.

## Local preview

Serve the repository root with any static HTTP server and open `index.html`.

## Publishing

The site is designed for a repository named `georgeathanaso.github.io` and can be published from the repository root with GitHub Pages.

Additional biography details remain intentionally unpublished until verified by the owner.
